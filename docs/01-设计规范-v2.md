# 设计规范 v2

> 替代 `docs/_archive/01-设计规范-v1.md`。结构改为三层：**不变量 → 密度 → 主题**。
> 原因见文末「修订说明」。**CI 只检查不变量，不检查主题数值。**

---

## 0. 三层结构（先读这个）

| 层 | 管什么 | 能不能改 |
| --- | --- | --- |
| **L1 不变量** | 永远成立的产品事实：中性色、无内容阴影、焦点可见、降低动效、性能约束 | 不改，改要 ADR |
| **L2 密度系统** | 一个系数 `D`，派生行高、间距、字号、图标、圆角 | 用户可调，预设三档 |
| **L3 主题** | 明暗、圆角族、强调色、弹簧参数、字体族 | 可整体替换，不进 CI |

v1 的最大问题：把三层混写，再把 L3 的数值接进 CI，导致**既不能换肤，也不能真调密度**。

---

## 1. L1 · 不变量

这十二条成立与主题无关，是 CI 唯一的检查对象。

1. **色彩中性**：应用背景必须接近 D65（中性灰），禁止带色温。我们是参考工具，不是滤镜。
2. **内容无阴影**：缩略图、卡片、列表项不加投影。
3. **层级靠发丝线 + 浮层阴影**：静态层级只用 `0.5px` 发丝线；只有浮层（胶囊、popover、对话框）允许两级阴影。
4. **内容要有边界**：缩略图必须带内描边 `0.5px rgba(0,0,0,0.10)`。真机测过：白底画作在 `#FAFAFA` 上，6% 完全看不见。
5. **焦点永远可见**：键盘焦点必须有 2px 可见环，且与「选中」形态不同。
6. **降低动效必须尊重**：`prefers-reduced-motion` 下没有位移与缩放。
7. **动画只动 `transform` / `opacity` / `filter`**，禁止 `width/height/top/left/box-shadow`。
8. **虚拟列表内禁止 `layout`**：未挂载的元素测不到起点。
9. **同屏动画节点 ≤ 48**：超出的瞬切。
10. **不硬编码视觉值**：颜色、间距、圆角、时长只允许来自 token。
11. **无 `transition: all`**。
12. **不引第二套同类依赖**（设计系统 / 图标库 / 动画引擎）。

## 2. L2 · 密度系统

### 2.1 密度是唯一自变量

```
D ∈ { 紧凑 0.85, 标准 1.00, 宽松 1.20 }
```

| 派生量 | 公式 | 紧凑 | 标准 | 宽松 |
| --- | --- | --- | --- | --- |
| 网格目标行高 | `220 × D`（四舍五入到 8 的倍数） | 184 | 224 | 264 |
| 网格 gutter | `行高 × 0.07`，取间距阶最近值 | 12 | 16 | 24 |
| 正文 | `13 × D`，取字号阶最近值 | 12 | 13 | 15 |
| 计数 / 角标 | `12 × D`，取阶，且不低于下限 | 11 | 12 | 13 |
| 侧栏行高 | `32 × D` | 28 | 32 | 40 |
| 图标 | 见下表 | 16 | 20 | 24 |

间距阶只允许：`4 / 8 / 12 / 16 / 24 / 32 / 48`
字号阶只允许：`11 / 12 / 13 / 15 / 17`

**关键规则**：用户调密度时，以上六项**必须一起变**。只改行高不改 gutter 和字号，是 v1 的错误。

### 2.2 圆角

圆角不随密度变，随**元素类型**变：

| 元素 | 值 |
| --- | --- |
| 缩略图 | 4 |
| 列表项、卡片 | 6 |
| 面板、对话框 | 10 |
| 胶囊、操作条 | 18 |

## 3. L3 · 色彩（中性主题）

### 3.1 表面

| Token | 值 | 说明 |
| --- | --- | --- |
| `--bg-app` | `#FAFAFA` | **中性**，不带色温 |
| `--bg-rail` | `#F4F4F4` | 侧栏 |
| `--bg-elevated` | `#FFFFFF` | 浮层 |
| `--bg-hover` | `rgba(0,0,0,0.045)` | |
| `--line-1` | `rgba(0,0,0,0.08)` | 界面发丝线 |
| `--line-content` | `rgba(0,0,0,0.10)` | **内容内描边**（实测 6% 在白底画作上不可见） |

### 3.2 文字

| Token | 值 | 用途 |
| --- | --- | --- |
| `--text-1` | `#1A1A1A` | 标题正文 |
| `--text-2` | `#5F5F5F` | 次级 |
| `--text-3` | `#999999` | 计数，**不得用于可点击操作，不小于 12px** |

### 3.3 状态

| Token | 值 | 用途 |
| --- | --- | --- |
| `--accent` | `#3E63DD` | **只用于链接** |
| `--danger` | `#B42318` | 破坏性操作 |
| `--success` | `#2F7A50` | 完成 |
| `--selection-ring` | `#1A1A1A` | 选中环（近黑，与内容无关） |

**焦点与选中的区分方式**：不用两种颜色，用**两种形态**——

- 选中：`1.5px` 近黑实线环，紧贴内容
- 焦点：`2px` 近黑**外偏移 2px** 环（`outline-offset: 2px`）

同屏出现时一眼可分，且不引入第二种颜色。

### 3.4 暗色

`--bg-app #101010` / `--bg-rail #161616` / `--bg-elevated #1C1C1C` / `--line-1 rgba(255,255,255,0.10)` / `--text-1 #F2F2F2`。暗色同样**中性**，不带蓝紫。

## 4. 字体

- 拉丁与数字：`Inter Variable`（本地自托管，不用 CDN）
- 中文：系统字体（`PingFang SC` / `Microsoft YaHei`），**不打包中文字体**
- **中文最小 12px，拉丁最小 11px**（Windows hinting 下中文 11px 发虚）
- 字号阶 `11 / 12 / 13 / 15 / 17`，标题最大 17
- 行高 1.45；字重只 400 / 500
- 数字一律 `tabular-nums`
- `letter-spacing` **禁止用百分比**（CSS 不支持，会静默失效）；中文不加字距

## 5. 动效

### 5.1 时长只管「非空间」变化

透明度、颜色、亮度过渡用三档：**140 / 200 / 280ms**，曲线 `cubic-bezier(0.2,0,0,1)`。

### 5.2 空间变化一律用弹簧

位移、缩放、FLIP、面板进出：**`stiffness 320 / damping 32`**，不写时长。
理由：同样的位移，距离不同，固定时长会显得「闪」或「拖」。弹簧按物理收敛，不需要时长。

### 5.3 FLIP 判断

**位置变了但元素是同一个 → FLIP；集合变了 → 只做透明度。**

| 场景 | 做法 |
| --- | --- |
| 密度档位切换 | 布局瞬切 + 140ms 整层交叉淡入，禁止逐项 FLIP |
| 排序 / 拖拽落位 | 弹簧 FLIP，≤ 48 节点 |
| 筛选 | 移除 140ms 淡出，新增 200ms 淡入 + 6px 上移，其余不动 |
| 视图切换 | 只对选中项共享元素过渡，其余瞬切 |
| 打开详情 | **手动 FLIP**（位移 + 缩放补间），不使用 `layoutId` —— 源缩略图在虚拟化/可滚动容器里，投影会被反复重算而卡住 |
| 侧栏拖动 | 弹簧 FLIP，≤ 50 行 |

## 6. 空间与布局

### 6.1 三种视图的语义（不变）

网格 = 扫描（自动布局，位置不持久）/ 画布 = 搭建（坐标持久）/ 无限 = 漫游（无边界，不持久）。

### 6.1.1 无限视图的实现约定

- 布局是「无限平面切格子，每格用哈希挑一张素材」：`pickAt(col,row)`，同一格永远同一张，滚动不会跳变
- 只渲染视口内的格子（视口外多留一圈缓冲），不需要预先知道总量
- 奇数行右移 1/3 格形成砖缝错位，每格 ±3% 尺寸扰动 —— 严格对齐会变成「表格」，看不出「没有边」
- 不做缩放，只做平移：滚轮累积成速度、惯性衰减到 0.5px/帧停住
- 视口位置要记忆（离开再回来停在原处），但**不存每张素材的位置**

### 6.2 极端比例降级

- 宽高比 > 8:1 或 < 1:8：该行**单独占一行**，高度按行高封顶，宽度自然，不强行撑满
- 单行单张且宽度 > 容器 60%：按 60% 显示，居中

### 6.3 位置信息（v1 的缺口）

侧栏折叠后，用户必须仍知道自己在哪。顶部左侧放**面包屑**：`库名 / 收藏集`，点击回退。胶囊居中，面包屑在左，右侧小胶囊（密度 / 排序 / 筛选）在右，三者不重叠。

### 6.4 多选与批量操作（v1 的缺口）

- 选中 ≥ 2 项时，底部居中浮出**操作条**（白底、圆角 18、浮层阴影）：归档 / 标签 / 删除 / 取消
- 出现：`translateY(8px) → 0` + 淡入，弹簧；消失 140ms 淡出
- 非选中项**不降透明度**（v1 的 0.6 会让视线乱跳），改为只给选中项加环

### 6.5 等待与渐进加载（v1 的缺口）

- **小于 300ms 的操作不显示任何进度**，避免闪烁
- 超过 300ms 才显示；超过 10s 必须可取消
- 缩略图未就绪时用**主色块**占位，不显示灰格，不做闪烁动画

## 7. 组件（关键项）

### 7.1 顶部胶囊

`240 × 36`、圆角 18、三段 `76 × 28`、距顶 12 居中。
滑块用 `layoutId` 共享元素，只有当前项渲染。实现见 `packages/ui/view-switcher/`。
快捷键 `Alt+1/2/3`。进入详情或过片时淡出。

### 7.2 网格

justified，每行等比撑满（误差 ≤ 0.5px），最后一行不缩放左对齐。
选中：近黑环（不用蓝）。悬停：`brightness 1.03`，视频静音播 3 秒。
缩略图 LOD：行高 < 140 用 64px，140–260 用 512，> 260 用 2048。

### 7.2.0 两种排布（右下角胶囊切换）

| 模式 | 算法 | 特征 |
| --- | --- | --- |
| 标准（对齐） | justified | 每行等高撑满，行列严格对齐；信息密度最高 |
| 瀑布（Pinterest） | masonry | 列宽固定、高度自由，投递到最短列；比例差异被保留 |

- 右下角是**一条工具带**：`− [滑杆] + ×1.4 │ 对齐 瀑布`，外壳统一由 `.grid-tools` 提供
- **缩放是倍率**（0.7–1.8），密度决定基准行高，滑杆只做乘法 —— 密度语义不被破坏，滑杆也不会跨档跳
- 拖动滑杆时**不加过渡**：60fps 的重排本身就是动画，再叠 380ms 补间只会拖慢手感
- 切换器固定右下角，胶囊 28 高，滑块用 `layoutId` 在两段间滑动
- **切换动效**：容器加 `data-morph` 480ms，`left/top/width/height` 各补间 380ms，
  并按索引做 6ms/项错峰（上限 150ms），形成从左上的铺开感
- **滚动时绝不能有这些过渡**，否则快速滚动会拖影 —— 只在 morph 窗口内生效
- 两种模式的极端比例都夹在 0.35–3.5，避免细长条

### 7.2.1 光标语义（六态，实测通过）

| 场景 | 光标 | 含义 |
| --- | --- | --- |
| 网格 / 画布 素材上 | `zoom-in` | 可打开看大图 |
| 画布素材上（未拖） | `grab` | 可拖动 |
| 画布拖动中（含平移空白） | `grabbing` | 正在拖 |
| 画布空白处 | `grab` | 可平移整个画布 |
| 详情浮层空白区 | `zoom-out` | 点一下退出 |
| 详情浮层图片上 | `default` | 点图不退出 |

要点：拖动状态不能只依赖 `:active` —— 指针捕获（`setPointerCapture`）之后 `:active` 不可靠，
必须在组件里记录拖动状态并输出 `data-drag`。

### 7.2.3 右键菜单

网格里右键任一素材：**打开 / 标签 ▸ / 删除**。

标签子菜单的排布规则（顺序固定，不随使用频率变）：

| 段 | 内容 | 交互 |
| --- | --- | --- |
| 已添加 | 该素材当前的标签 | 左对齐勾选，再点一次移除 |
| 常用 | 全库频次最高的标签（排除已添加） | 右侧显示使用次数 |
| 添加标签… | 内联输入框 | 回车即添加并应用，Esc 取消 |

- **点一次切换，菜单不关** —— 连着打几个标签是常规操作
- 未选中的行也占住勾的位置，文字不左右跳
- 悬停即打开子菜单；点击是「打开」而不是「切换」，否则悬停后再点会把它关掉
- 右键落在未选中的素材上时，先把它变成当前选中（跟系统习惯一致）

### 7.2.2 详情展开：同元素位移 + 网格退场

双击缩略图时，**不是「盖一层浮层」，而是「那张图长大」**：

1. 被点中的格子 90–120ms 内先消失（它的任务交给浮层里的同元素）
2. 其余格子按「与被点中的距离」错峰退场：`delay = min(|Δindex| × 6, 180)ms`，
   同时 `opacity → 0`、`scale → 0.92` —— 视觉上像被中间那张推开
3. 遮罩**晚 60ms** 才压上来（0.26s 渐变）。先让人看见网格退场，再盖住；
   如果遮罩立刻到位，用户只看到「黑屏 + 大图」，退场白做
4. 关闭时顺序反过来：遮罩 0.16s 淡出，格子按同样的错峰回来

为什么用「手动 FLIP」而不是 `layoutId`：源缩略图在虚拟化 + 可滚动容器里，
motion 会反复重算投影目标，动画会卡在中途（实测停在 0.36 倍）。

### 7.3 详情浮层

遮罩 `rgba(20,20,20,0.72)`，图片最大 `90vw × 82vh`，保持原始宽高比（`object-contain`）。
打开从缩略图 FLIP 放大，关闭 200ms 淡出。右侧面板 280，只显示文件名、尺寸、来源、标签、收藏集。

### 7.4 过片

全屏深色（`#0F0F0F`，不透明）。信息不占横条，压成图上角标——**全产品唯一允许在内容上压深色的地方**。

四层结构，自上而下：

| 层 | 内容 | 规格 |
| --- | --- | --- |
| 顶栏 | 左「还剩 N 张 · 共 M」／右「退出 Esc」 | 56 高，字号 12，`rgba(255,255,255,.55)` |
| 舞台 | 大图居中 + 两侧圆形箭头 | 图最大 `82vw × 72vh`，圆角 8，`.5px` 内描边；箭头 36 圆，`rgba(255,255,255,.42)`，hover 才显形 |
| 胶片条 | 队列全景，当前项放大 | 行高 88；普通 44，当前 60 + `0 0 0 1.5px #fff` 双环；可横向滚动，自动居中当前项 |
| 操作行 | 1–4 归档 / T 标签 / Del 丢弃 | 芯片 28 高，圆角 14，`.5px` 描边 |

角标：左下 14/14，`rgba(0,0,0,.58)`，圆角 8，内含文件名（500）+ 尺寸（`rgba(255,255,255,.6)`）。
键位提示在最底一行，字号 11，`rgba(255,255,255,.38)`——**比操作行更轻，是备忘不是界面**。

为什么把信息条换成角标：整屏只服务一件事——看图和决定。56px 的横条会把注意力从图上拉走，
而角标在需要时读得到、不需要时不占版面。胶片条同时给出「还剩多少」的空间感，比数字更准。

### 7.5 反馈

Toast 底部居中，含撤销文字按钮。导入进度不弹模态。空态一句话 + 一个动作。

## 8. 主题（可整体替换）

以下都属于 L3，换它们不需要改 CI：

- 明暗主题（中性浅色 / 中性深色）
- 圆角族（4/6/10/18 为标准，可整体换成 0/4/8/16 或 6/8/12/20）
- 强调色（只用于链接与状态）
- 弹簧参数（默认 320/32，可换 400/40 更紧致）
- 字体族（Inter / 系统字体 / 其它无衬线）

## 9. 可访问性与国际化

- 键盘可达全部操作；焦点可见；Tab 顺序与视觉顺序一致
- 文字对比度：正文 ≥ 4.5:1，大字 ≥ 3:1；`--text-3` 仅用于非必要信息
- **色彩筛选不能只给色块**：必须同时给色名（如「砖红」「灰绿」），并支持按亮度 / 饱和度筛选
- 触屏目标 ≥ 40px（密度紧凑时也不得更小）
- 高对比度模式下，发丝线升级为 1px 实线
- 文案中文优先，数字与单位统一（尺寸用 `1920 × 1080`，时长用 `0:12`）

## 10. CI 断言（只查 L1）

| 规则 | 检查方式 |
| --- | --- |
| 禁止硬编码颜色 / 间距 / 圆角 / 时长 | 脚本扫描 hex、rgb()、px 字面量（白名单：token 文件） |
| 禁止 `transition: all` | stylelint |
| 禁止 Tailwind 颜色 / 圆角 / 阴影类 | stylelint 选择器白名单 |
| 禁止 import 图标包（`packages/ui` 除外） | ESLint `no-restricted-imports` |
| 禁止 `framer-motion` 包 | ESLint + package.json 检查 |
| 缩略图必须有 `--line-content` 内描边 | 组件测试 + 截图基线 |
| 焦点态存在且可见 | Playwright 键盘走查 + 截图 |
| `prefers-reduced-motion` 下无位移 | Playwright 模拟后截图对比 |
| 网格中不出现 `layout` 动画 | 代码扫描 + 性能基准 |
| 色彩筛选有色名 | 组件测试 |

**不写进 CI 的**：具体 hex、圆角数值、字号数值、动效时长数值、弹簧参数。它们属于 L3。

## 11. 走查清单

1. 背景是否中性？浅色素材在白底上是否仍有边界？
2. 调密度时，行高、gutter、字号、图标是否**一起**变了？
3. 焦点与选中同屏时能否一眼区分？
4. 侧栏折叠后，还能知道自己在哪个收藏集吗？
5. 多选后，批量操作条是否出现？
6. 极端宽高比的图有没有被压成一条线？
7. 小于 300ms 的操作有没有乱弹进度？
8. 色盲用户能否完成色彩筛选？
9. 降低动效后是否还有位移？
10. 空态、加载、错误三态是否都写了？

## 12. 修订说明（为什么抛弃 v1）

| v1 的问题 | 性质 | v2 的改法 |
