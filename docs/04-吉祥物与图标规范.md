# 吉祥物与品牌图标规范

> 吉祥物：**眼珠球**。一个近黑圆角方块，两只眼睛贴在球面上，会跟着光标看。
> 来源：用户提供的 `Watcher` 实现（球面投影 + 弹簧 + 眨眼），本仓库版本见 `packages/ui/mascot/`。

---

## 1. 为什么是它

- **有生命感但不吵**：它只在被看的时候动，不抢内容注意力，符合「界面 95% 让位给素材」的原则。
- **几何本身能当图标**：圆角方块 + 两只眼，在 16px 下依然读得出，不需要另一套品牌图形。
- **和产品语义对得上**：一个「在看」的东西，正是一个视觉参考库该有的姿态。

---

## 2. 几何

| 项 | 值（100 单位坐标系） |
| --- | --- |
| 身体 | 圆角方块，外框 6 → 94，圆角 24（略小于 iOS 的 22.4%，接近 Windows 11 观感） |
| 眼睛（大尺寸） | 宽 10.12 / 高 17.6 / 圆角 5.06（胶囊形竖眼） |
| 眼距 | 中心各偏移 16.28（身体宽度的 18.5%） |
| 安全边 | 外侧留 6% 透明边，供任务栏与资源管理器裁切 |
| 安全描边 | 白 12% 透明、0.6 单位，仅在 ≥32px 使用（深色任务栏上勾出轮廓；小尺寸会变成噪点，关掉） |

---

## 3. 尺寸档位（关键）

| 尺寸 | 眼型 | 说明 |
| --- | --- | --- |
| 16 / 24 | **圆点眼**（直径 22% 身体宽） | 竖眼在这个尺寸只剩 1.5px，会糊成一条线；改用圆点保识别 |
| 32 及以上 | **竖眼** | 品牌标准形态 |
| UI 内 | 竖眼 | 空态 96 / 关于页 180，不要超过 180 |

组件里 `eyes="auto"` 会在 32px 以下自动切换，不需要手动传。
界面内的尺寸跟密度 token `--mascot-size` 走：紧凑 80 / 标准 96 / 宽松 112；
只有显式传 `size` 时才覆盖它（16–180）。容器（如欢迎页的 `.library-mascot`）与它同源，不再各自算一套。

---

## 4. 颜色

| tone | 身体 | 眼睛 | 用在 |
| --- | --- | --- | --- |
| `ink`（默认） | `--text-1`（#1A1A1A） | `--bg-app`（#FAFAFA） | 亮色界面的图标、空态、关于页 |
| `paper` | `--bg-elevated` | `--text-1` | 深色背景、深色启动图 |

- 不允许渐变、阴影、内发光。
- 不允许把眼睛改成强调色（#3E63DD）—— 强调色只表示状态。

---

## 5. 动效参数

| 行为 | 参数 |
| --- | --- |
| 跟随光标 | 一条弹簧：`k = 0.06`，阻尼 `d = 0.34 − bounce × 0.22`（bounce 默认 30） |
| 追随强度 | `follow` 默认 60，`tanh` 曲线，边缘最大偏移 0.85R |
| 眨眼 | 160ms 一闭一开，间隔 2.6–5.8s 随机；idle 模式固定 2s |
| 环顾 | idle 模式每 5s 看向随机方向 900ms，然后回正 |
| 按压 | `scale 0.96`，140ms 回落 280ms 弹簧 |
| 降低动效 | `prefers-reduced-motion` 下取消追随与按压，只保留直视角色的静态帧 |

---

## 6. 性能（对原实现的两处改动）

1. **停帧**：原实现每帧都重排 `requestAnimationFrame`，等于一颗常驻 60fps 的动画。现改为收敛后真正停止，只在下一次眨眼前唤醒，指针移动时唤醒。
2. **容器选择器**：原实现写死了 `.bench-card, .dtl-block, ...`，改为 `[data-mascot-frame]`，需要一个容器就给它加这个属性。

另外保留了两条：`IntersectionObserver` 离开视口停、`visibilitychange` 切后台停。

---

## 7. 出现位置

| 位置 | 形态 | 说明 |
| --- | --- | --- |
| 应用图标 / 任务栏 / 开始菜单 | 静态 | 16–256 全套，见 §9 |
| 启动窗口 | `idle` 96px | 只眨眼与环顾，不跟随（启动时鼠标还没进窗口） |
| 空库 / 空收藏集 | `idle` 96px + 一句话 | 不做插画，就它一个 |
| 关于页 | `follow` 180px | 唯一允许跟随光标的地方 |
| 导入完成 | 静态 + toast | 不要弹窗式庆祝 |
| 错误页（库损坏） | `idle` 96px | 表情不变，不卖萌 |

**不要出现**：网格里、工具栏里、每个设置项旁边、加载中的骨架里。它一多就从「角色」变成「贴纸」。

---

## 8. 禁止用法

1. 旋转、拉伸、非等比缩放（圆角会变形）
2. 加投影、描边光、玻璃质感
3. 换成彩色身体或渐变身体
4. 在深色背景上用 `ink`（黑底黑球）
5. 跟随光标的同时又做随机抖动
6. 同时出现两个以上（例外：关于页的形态对照）
7. 把眼睛做成加载指示器（它不是 spinner）

## 9. 资产与再生成

```
assets/brand/app-icon.svg        矢量母版（100 单位，与组件同几何）
assets/brand/app-icon-{16..512}.png   每档原生渲染（SDF 抗锯齿）
src-tauri/icons/icon.ico         16/24/32/48/64/128/256（≤128 用 BMP，256 用 PNG）
src-tauri/icons/{32x32,128x128,128x128@2x,icon}.png   Tauri 约定名
```

再生成：`python scripts/gen-icons.py`（纯标准库，无 Pillow 依赖）。

---

## 10. 无障碍

- 有语义时：`role="img"` + `aria-label="会跟着光标看的吉祥物"`（组件已内置）
- 纯装饰时：外层加 `aria-hidden="true"`，并从 tab 序列移除
- 不承载任何操作：可点说话只是彩蛋，所有功能都有正常入口
- 降低动效时不得有任何位移或缩放
