# 图标覆盖核对 · akar-icons

> 结论：**82 项需求，74 项命中，缺口 8 项（9.8%），低于 15% 的换库阈值 → 维持 akar-icons，缺口自绘补齐。**
> 核对基准：`akar-icons@1.9.31`，共 434 个图标（实读 `dist/icons.d.ts`，非文档转述）。

---

## 1. 核对方法

1. 从三份文档（方案 v2、设计规范 v1、依赖清单）里抽出产品所需的全部图标语义，去重后 **82 项**；
2. 逐项在 434 个名称里找语义对应，**允许改名**，不允许「长得像但意思不同」；
3. 单独标记「语义偏差但可先用」，这类不算缺口，但列出来免得后面踩坑；
4. 缺口判定标准：M1 需要的算 P0，M2 画布阶段需要的算 P1。

## 3. 缺口清单（8 项）

| # | 图标 | 用于 | 优先级 | 自绘方向 |
| --- | --- | --- | --- | --- |
| 1 | 密度档位 | 顶部小胶囊 | **P0** | 三条横线，长度递减（16px 时降为两条） |
| 2 | 色板 | 色彩筛选、标签色 | **P0** | 经典 palette：椭圆盘 + 2–3 个取色孔，或简化为九宫格圆点 |
| 3 | 画布视图 | 顶部胶囊第三段 | P1（M2） | 带轻微透视的方框，内部两张错落小卡，与 `Grid` 的正交格子形成对比 |
| 4 | 套索 | 画布工具条 | P1 | 不规则闭合曲线 + 尾部小箭头 |
| 5 | 成组 | 画布工具条 | P1 | 两个方块 + 四角括号 |
| 6 | 解组 | 画布工具条 | P1 | 两个方块向外分离，去掉括号 |
| 7 | 图层顺序 | 画布工具条 / 右键菜单 | P1 | 三个菱形错位叠放 |
| 8 | 分布 | 画布工具条 | P1 | 三条竖线，中间夹双向箭头 |

**P0 只有 2 个**，都在 M1 之前必须补齐；P1 的 6 个集中在 M2 画布阶段，其中 5 个（套索、成组、解组、图层、分布）属于同一套「画布工具」视觉族，可以一次画完保证风格统一。

## 4. 需要留意的 6 处语义偏差

| 需求 | 现状 | 处理 |
| --- | --- | --- |
| 重做 | `ArrowClockwise` 与「刷新」同形 | 重做/刷新不要同时出现在同一工具条 |
| 适配窗口 | `Enlarge` 是双向箭头放大 | 与 `Reduce` 成对使用，含义靠 tooltip 补 |
| 旋转 | `ArrowCycle` 是首尾相接的循环箭头 | 若画布需要旋转手柄图标，归入自绘 |
| 在文件夹显示 | 复用 `Folder` | 与「收藏集」同形，需靠上下文区分 |
| 宽高比 | `Frame` 是裁切框 | 用于比例筛选可用，但不要与「画布画框」混用 |
| 导入 | `CloudUpload` 暗示上传到云 | 本地导入也可用，但不要给用户「文件已上传」的误读 |

## 5. 自绘规范（8 个图标统一）

- 画布 `24 × 24`，视觉主体控制在 `18 × 18` 内，四周留 3px 安全边
- 描边 `2px`（与 akar 基准一致），`stroke-linecap="round"`、`stroke-linejoin="round"`
- 只用 `currentColor`，不设固定色
- 尺寸三档：24 / 20 / 16；**16px 档必须单独简化**（去掉内部细节，只保留外轮廓）
- 与 akar 同以「圆角几何」为基础：不用直角折线，拐点统一 2px 圆角
- 文件放置：`packages/ui/icons/<name>.tsx`，与 akar 一起从 `packages/ui/icon.tsx` 导出，业务层无感知

## 6.1 补充：不能直接依赖 akar（实测）

`akar-icons` 是 **CJS 单文件包**（`main: dist/index.js`，没有 `module` / `exports`），
十个图标直接把 434 个全打进产物：**343KB → 683KB（+340KB）**。

改为**构建期提取**：`scripts/gen-icons.mjs` 用 `renderToStaticMarkup` 把用到的图标
渲染成静态 SVG，写进 `packages/ui/icons.generated.tsx`。
- 图形与 akar 完全一致（同一条 path 数据）
- 运行时零依赖，产物回到 344KB
- `akar-icons` 降为 `devDependencies`，只给生成器用

新增图标：在 `scripts/gen-icons.mjs` 的 `PICK` 里加一行，跑一次生成脚本。

## 6. 决策

- **维持 akar-icons**，不换 Phosphor。理由：覆盖率 90.2%，缺口里一半是画布专用图形（任何通用图标库都缺），换库并不能消灭这些缺口，只会多一套线宽。
- **自绘 8 个**，P0 两个在 M0 内完成，P1 六个在 M2 画布动工前完成。
- **禁止**为了这 8 个图标引入第二个图标库。
- 若日后 akar 覆盖需求跌到 85% 以下（例如需要大量文件类型图标），再整体评估换库，仍不允许混用。
