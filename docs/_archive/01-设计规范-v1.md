# 设计规范 v1 · 亮色优先

> 决策：亮色为主设计对象，暗色跟随系统（M2 补齐映射）；三视图切换 = 顶部居中胶囊
> 目标：Atlas 式的「界面消失」，所有规则必须可断言，供 AI 团队执行与 CI 校验

---

## 1. 六条原则（每条都能被检查）

1. **视觉重量预算 95/5**：界面元素的对比度不得超过其服务内容的平均对比度。常态下不出现常驻工具栏、卡片投影、分隔线。
2. **空间连续性**：网格→详情是同一元素放大（FLIP），画布缩放按物理比例，离开视图再回来视口不变。
3. **密度节奏**：间距只取阶值；`gutter = 目标行高 × 0.05–0.08`，三者比例锁定。
4. **动效只动物理属性**：时长三档、弹簧曲线、同时动画属性 ≤ 2、只允许 transform / opacity / filter。
5. **材质中性**：不用纯黑纯白；相邻表面明度差 ≤ 6%；强调色只做状态。
6. **字体窄区间**：五档字号、两档字重、数字用 tabular-nums。

## 3. 间距与圆角

| 类别 | 允许值 | 用法 |
| --- | --- | --- |
| 间距阶 | `4 / 8 / 12 / 16 / 24 / 32 / 48` | 禁止 10、14、18 等随手值 |
| 圆角 | `4` 缩略图 · `6` 列表项与卡片 · `10` 面板与对话框 · `18` 胶囊 | 只允许这四个值 |
| 行高档位 | `S 160 / M 220 / L 300` | 与 gutter 联动：S→8、M→16、L→24 |
| 网格内边距 | `24` | 容器四周，滚动条区域不额外留白 |

## 4. 字体与排版

- 字族：`Segoe UI Variable, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号只允许：`11 / 12 / 13 / 15 / 17`
- 行高 `1.45`；字重只有 `400 / 500`
- 所有数字使用 `font-variant-numeric: tabular-nums`
- 标题最大 17px，靠留白立层级，不靠字号
- 中文不设 letter-spacing；拉丁小字（11–12px）加 `0.01em`

## 5. 图标

- 库：`akar-icons`（MIT，434 个），经 `packages/ui/icon.tsx` 单一出口；覆盖核对见 `docs/03-图标缺口核对.md`
- 尺寸档：`16 / 20 / 24`，描边固定 `2`（akar 的设计基准，不改成 1.5）
- 颜色继承 `currentColor`，默认取 `--text-2`
- 命名映射：`Undo→ArrowCounterClockwise`、`Close→Cross`、`Trash→TrashCan`、`Settings→Gear`、`Infinity→Infinite`
- 缺口语义共 **8 项**（覆盖率 90.2%，已核对）：密度、色板、画布视图、套索、成组、解组、图层、分布 → 自绘，24px / 2px 描边 / 圆角端点，详见 `docs/03-图标缺口核对.md`
- 禁止业务代码直接 import `akar-icons` 或 `lucide-react`

### 5.1 吉祥物（不属于图标库）

产品吉祥物是**眼珠球**（近黑圆角方块 + 两只贴在球面上的眼睛），与应用图标同源几何。代码在 `packages/ui/mascot/`，规范见 `docs/04-吉祥物与图标规范.md`。

- 不参与图标库替换，也不允许用 akar 里的任何图标替代
- 尺寸 16/24 用圆点眼，32 以上用竖眼（组件 `eyes="auto"` 自动切换）
- 颜色只有 `ink`（近黑身体白眼）与 `paper`（浅色身体墨眼）两种，不做彩色、不做渐变
- 允许出现的位置只有：应用图标、启动窗口、空态、关于页、导入完成、错误页

## 6. 动效

| 类别 | 值 |
| --- | --- |
| 时长 | `140ms` 快（hover、按压）· `200ms` 常规（切换、滑块）· `280ms` 空间（FLIP、面板进出） |
| 曲线 | 弹簧 `damping 32 / stiffness 320`；透明度用 `cubic-bezier(0.2,0,0,1)` |
| 允许动画属性 | `transform`、`opacity`、`filter: brightness()` |
| 禁止 | `width/height/top/left`、`box-shadow`、`border-radius` |
| 同时动画属性 | ≤ 2 |
| 悬停 | `scale 1.015` + `brightness 1.03`，**不位移、不加阴影** |
| 按压 | `scale 0.97` |
| 降低动效 | 所有动画在 `prefers-reduced-motion` 下降级为纯透明度切换 |

## 7. 组件规范

### 7.1 顶部胶囊（视图切换）

- 尺寸 `240 × 36`，圆角 `18`，`--bg-elevated` + `--line-1` + `--shadow-float`
- 距窗口顶部 `12`，水平居中，滚动时固定不动
- 三段等分 `76 × 28`，内边距 `4`：网格 / 画布 / 无限
- 当前项：填充 `#1A1A18`、文字 `#FFFFFF`；其余：`--text-2`
- 切换：滑块 `200ms` 弹簧移动，图标不做形变
- **滑块用 `layoutId` 共享元素实现**：只有当前项渲染滑块，motion 自动从旧位置飞到新位置。这是 `layoutId` 唯一无可替代的用法
- 实现见 `packages/ui/view-switcher/`，动效参数一律来自 `packages/ui/motion-tokens.ts`（`SPRING` / `DUR`）
- 快捷键 `Alt+1 / 2 / 3`
- 右侧 `8` 间距放一个独立小胶囊 `28 × 28 × 3`：密度、排序、筛选（图标按钮，点击弹出 popover）
- 进入详情 / 过片时胶囊 `opacity → 0`（140ms），退出恢复

### 7.2 侧栏

- 展开 `240`；折叠为 0（浮层形式滑出，不挤压内容），`Ctrl+B`
- 结构：库名 → 收件箱（带计数）→ 收藏集树 → 标签 → 设置
- 行高 `32`，圆角 `6`，缩进 `12`/层，悬停显示 `⋯`（常态隐藏）
- 计数用 `--text-3`、11px、tabular-nums；收件箱计数仅在 > 0 时显示
- 树最多 3 层，超过层级时「新建子集」置灰并给出说明

### 7.3 网格（核心）

- 布局：justified，每行等比撑满容器（误差 ≤ 0.5px），**最后一行不缩放、左对齐**
- 容器内边距 `24`，`gutter` 与行高档位联动
- LOD：行高 < 140 → 64px 缩略图；140–260 → 512px；> 260 → 2048px
- 单张超大图限制：宽度不超过容器 60%
- 状态：
  - 默认：无边框无阴影
  - 悬停：`brightness 1.03`，视频静音播放 3 秒后停，右下角 11px 时长角标
  - 选中：**双环**——内 `1px #FFFFFF`、外 `1.5px #1A1A18`（适配任意明暗素材），不用蓝色高亮
  - 多选：非选中项 `opacity 0.6`
  - 拖拽：`scale 0.96`、`opacity 0.9`
- 交互：单击选中 · 双击或 `Enter` 打开详情 · `Space` 快速预览 · 方向键移动焦点 · `Ctrl+A` 全选 · 空白处点击取消选择 · 拖拽框选
- 链接类：优先 `og:image`；抓不到时用「站点品牌色块 + favicon + 标题」，**不允许裂图**

### 7.4 详情浮层

- 遮罩 `rgba(20,20,20,0.72)`，图片最大 `90vw × 82vh`，圆角 `2`（几乎无圆角）
- 打开：从缩略图位置 FLIP 放大，`280ms` 弹簧；关闭 `200ms`
- 右侧面板 `280`，`--bg-elevated`：文件名、尺寸、类型、来源链接、标签、收藏集；EXIF 等折叠
- `Esc` 关闭，`← →` 切换上一张/下一张，`Space` 播放视频

### 7.5 过片（收件箱）

- 全屏遮罩，图片居中最大 `88vh`
- 底部 `56` 高信息条：`rgba(0,0,0,0.55)` 白字 12px，**这是全产品唯一允许在内容上压深色的地方**
- 键位提示放右下角，首次显示 8 秒后淡出，可在设置改为常显
- 顶部左侧「还剩 N 张」，11px `--text-3`（在遮罩上改为白 62%）

### 7.6 反馈

- Toast：底部居中，`--bg-elevated`，圆角 `10`，`--shadow-float`，含撤销文字按钮
- 导入进度：胶囊内 `240 × 4` 近黑进度条，不弹模态
- 空态：一句话 + 一个动作，不配插画、不写笑话

### 7.7 重排序与布局过渡（FLIP）

**先做一个判断**：位置变了但元素还是同一个 → 用 FLIP；元素的集合变了 → 只做透明度，不做位置动画。把这两件事混在一起，是所有「重排乱飞」的根源。

| 场景 | 动画 | 参数 | 范围限制 |
| --- | --- | --- | --- |
| 密度档位切换（全部项同时改尺寸） | 布局**瞬切**，整层交叉淡入 | 140ms，只动 opacity | 禁止逐项 FLIP |
| 排序方式改变 / 拖拽落位 | 单次 FLIP | 200ms spring(32/320) | 只对已挂载项，≤ 48 个 |
| 筛选 / 标签切换 | 移除 140ms 淡出；新增 200ms 淡入 + 6px 上移 | opacity + translateY | 其余项**不动** |
| 视图切换 grid ↔ canvas ↔ infinity | 只对**选中项**做共享元素过渡，其余瞬切 | 280ms FLIP | 一次最多 1 个元素 |
| 打开详情 | 缩略图 → 浮层 | 280ms spring | 唯一允许大范围 `layoutId` 的地方 |
| 侧栏收藏集拖动 | 200ms FLIP | spring | 行数 ≤ 50 |

**技术约束**

- **虚拟列表内禁止 `layout`**：未挂载的元素没有 DOM，量不到起点，动画会「从左上角飞过来」
- `layout` 每帧读取布局，会强制重排；同一容器内同时参与动画的元素上限 **48**
- 禁止 `layout` 与 `AnimatePresence` 的 exit 同时作用于同一批元素（会产生占位抖动）；`mode="popLayout"` 只允许用于 ≤ 12 项的小集合（详情面板、画板缩略图切换），网格的筛选与切换一律用透明度
- 包名是 `motion`，import 路径 `motion/react`；项目中不允许出现 `framer-motion`（同源旧名，装两套等于两份运行时）
- 参数一律来自 token，不写 JS 常量（`stiffness: 500` 这类值不允许出现在组件里）

**`layoutId` 的两条经验**

1. 胶囊滑块用它是对的 —— 同一个元素在两个位置之间移动。
2. 图片展开时**必须保持宽高比**：从 4:5 的缩略图放大到 4:3 的容器会产生拉伸。预览层用 `object-contain`，或让容器比例跟随素材本身。

**反例**：把 `layout` 广播到整个网格。3 张图时看起来很漂亮，3000 张时就是一场性能事故 —— 这是这类产品最常见的翻车点。

## 8. 空态 / 加载 / 错误

| 场景 | 做法 |
| --- | --- |
| 空库 | 一行说明 + 主按钮「拖入文件或粘贴图片」 |
| 加载中 | 骨架屏用 `--bg-hover` 填充、圆角 4，不做闪烁动画 |
| 缩略图未就绪 | 显示主色块占位（取 `dominant_color`），不显示灰格 |
| 文件未下载 / 离线 | 主色块 + 右下角 12px 云朵角标，点击触发下载 |
| 文件缺失 | 主色块 + `--danger` 细边 + 「文件已移动」提示 |

## 9. 反例清单（出现即返工）

1. 卡片投影 + 大于 10px 的内容圆角
2. 彩色标签墙、渐变按钮、玻璃拟态
3. hover 放大到 1.1 或加位移/阴影
4. 同时动三个以上属性，或用 `ease-in-out` 包一切
5. 纯黑 `#000` 背景 + 纯白 `#FFF` 文字
6. 每个列表项都加边框
7. 同一界面混用两套图标线宽
8. 用蓝色块表示选中（内容上的选中必须用双环）
9. 三级文字用于可点击操作
10. 数字不用 tabular-nums

## 10. 可断言规则（接 CI）

| 规则 | 检查方式 |
| --- | --- |
| 圆角只允许 4 / 6 / 10 / 18 | stylelint `declaration-property-value-allowed-list` |
| 间距只允许阶值 | 自定义脚本扫描 padding/margin/gap 的 px 字面量 |
| 动效时长只允许 140 / 200 / 280 | stylelint 正则 |
| 禁止 `transition: all` | stylelint `declaration-property-value-disallowed-list` |

| 字号只允许 11 / 12 / 13 / 15 / 17 | stylelint 正则 |

## 11. 走查清单（每个新页面提交前）

1. 截图里能否一眼看出内容在哪？界面元素是否抢了注意力？
2. 任意两个相邻表面的明度差是否 ≤ 6%？
3. 每个可点击元素是否有 hover 与 focus 两态？focus 是否用 `--accent` 环？
4. 所有间距是否都来自阶值？
5. 动画是否只用了 transform / opacity？时长是否在三档内？
6. 暗色模式下（M2 起）是否有任何硬编码颜色？
7. 空态、加载态、错误态是否都写了？
8. 数字是否 tabular-nums？中文是否没有多余 letter-spacing？

## 12. 与 Arc Library 的差异覆写

| Arc 默认 | 我们的覆写 |
| --- | --- |
| 圆角 8–12 | 4 / 6 / 10（面板）/ 18（胶囊） |
| 多级阴影 | 只保留 `--shadow-float` 与 `--shadow-modal` |
| 按钮 hover 位移 | 去掉位移，只保留 `brightness` |
| 动效 token 较多 | 收敛为 140 / 200 / 280 三档 |
| 标签 morph 的模糊交叉淡入 | 只用于状态切换（保存→已保存），列表内禁用 |
