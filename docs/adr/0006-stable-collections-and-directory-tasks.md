# ADR 0006：稳定收藏集与可恢复的整目录操作

日期：2026-10-29。状态：本地目录子阶段已实施。

## 背景

此前收藏集由路径生成，改名后成为另一个标识；素材只有相对路径，不能区分已回收的旧收藏集与原地址新建的同名目录。文件级回收不能承担整目录的空集保留和祖先删除规则。

## 选项

1. 延续路径标识，整目录回收遍历并给所有后代写删除。会改变目录身份，产生大量墓碑并覆盖后代原有回收状态。
2. 持久化收藏集和父子身份，素材关联目录；祖先墓碑在查询时生效。整目录文件操作采用单独持久任务和完整树校验。

## 决定

采用选项 2，没有新增依赖或修改设计 token。

- 新测试库数据库结构为 schema 5，保留 manifest 格式 1。旧结构明确拒绝打开，不自动升级或改写用户文件，符合当前工程验证阶段不做旧版兼容的约定。
- `collections` 保存客户端生成的 UUIDv7、父身份、名字、相对位置、文件身份和可用状态；`items.collection_id` 保存所属收藏集。同级名字唯一，素材名在所属目录内唯一；原地址新建同名收藏集使用新身份。
- `v_collections_visible` 递归过滤自身及祖先墓碑，`v_items_visible` 与标签读取沿用该可见性。整目录回收只修改所选祖先的删除序号，素材、子收藏集、标签及已有单项回收记录不级联改删除状态。
- 外部目录事实加入扫描清单。纯 TS 优先使用唯一文件身份、其次现有路径匹配目录，再生成新身份并提交明确变更；Rust 只复核身份、位置、父子约束及当前版本后持久化。Windows 目录句柄使用 `FILE_FLAG_BACKUP_SEMANTICS`；文件身份仍受卷和文件系统限制，不能当跨卷永久身份。
- 素材浏览与收藏集计数按身份和子树计算，路径继续参与显示、搜索与普通文件访问。目录改名和移动更新位置索引，保留主键与素材关系；原路径来源映射可由当前来源对象身份解析，并随文件核对更新。隐藏祖先的来源重新导入不会复活原对象。
- 每个目录任务记录根身份、相对位置和完整树（普通隐藏文件、空目录、大小、完整 SHA-256）。预览 token 为根身份及完整树的 SHA-256；确认时内容版本改变则拒绝旧预览。
- 执行顺序为“准备记录 → 移到库内暂存 → 不覆盖发布目标 → 树/身份校验 → SQLite 提交 → 完成记录/归档”。统一暂存步骤覆盖仅大小写改名。回收目标为 `.ceas/trash/<task>/<原相对位置>`；暂存为 `.ceas/directory-staging/<task>`，任务在 `.ceas/directory-operations`。
- 恢复预览对磁盘和可见收藏集的冲突都保留双方；不合并已有目录。源、暂存、目标不明确时保留现场及任务。未移动且前置状态满足时可取消；已暂存的移动/恢复任务可另选目标继续。启动先恢复目录任务，再恢复文件任务；未完成目录任务阻止冲突文件写入和根目录迁移。
- UI 提供“管理收藏集”、收藏集回收站、改名/移动/回收/恢复预览、确认及任务处理。管理期间自动核对暂缓，可手动核对；关闭后继续。面板最多先显示 100 项，可继续加载。取消表单、完成操作和 Esc 都有明确回焦。
- 目录索引一次建立父子映射，再按祖先累计计数，避免逐目录反复建树；无变化事实不提交目录更新。性能测量只覆盖纯计算。

## 代价与边界

完整树的反复校验增加读盘成本，当前只有忙碌提示和预览总量，尚无逐文件目录任务进度或运行中主动停止。外部在暂存中修改内容会阻止重放并保留现场，接受变更/修复向导尚待补。此阶段没有永久删除或自动空间回收。

目录身份不可获得且路径改变时，旧目录保留缺失记录，新位置不能自动确认原身份；手动关联目录向导仍待补。稳定标签关系、备份/独立副本/修复 UI、完整任务历史、文件级迁移续传和原生媒体边界仍未完整实施。没有用本机同卷和进程中断测试代替跨物理卷、移动介质、网络共享盘、真实断电或一万文件端到端验收；Linux、网页、PWA/ZIP 仍后续。
